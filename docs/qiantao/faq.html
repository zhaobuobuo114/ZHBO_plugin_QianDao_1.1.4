QianDao · 常见问题

安装与启动

插件显示红色 / 加载失败

  • 确认服务端是 1.12.2，且核心为 Spigot 或 Paper。
  • 确认 Java 版本 ≥ 8。
  • 查看控制台完整报错，常见原因是核心版本不匹配或 jar 损坏（重新下载）。

启动后没有生成 config.yml

检查 plugins/ 目录写权限，或插件是否真的被加载（控制台应有 QianDao 签到插件已启用）。

签到与奖励

签到成功但没收到金币

  1. 看启动日志的 金币联动: 输出，已关闭 说明没检测到前置。
  2. 确认 economy.type 与已安装插件一致（zpoints / playerpoints / vault）。
  3. 前置装好后执行 /qd reload，再签到测试。

改了奖励物品没生效

  • 确认执行了 /qd reload。
  • 检查 cycle 对应天的 commands 是否写对，%player% 不能丢。
  • 指令由控制台执行，测试时注意控制台是否报“未知指令”。

第 8 天奖励为什么回到第 1 天

这是设计如此：7 天一个周期，第 8 天重新从第 1 天开始，连续签到天数继续累计，用于触发 7 / 14 / 30 天里程碑。

连续天数突然归零

连续链必须以“今天”或“昨天”结尾。超过一天没签到，getStreak 判定为断签，连续天数归零，里程碑记录也会在新一轮重新计算。

补签

补签面板里没有可选日期

补签只列出：

  • 最近 buqian.max-days 天内
  • 在该玩家首次签到之后
  • 当日既没正常签到也没补签过

新玩家没有历史记录，自然没有可补签日期。

补签卡怎么获得

三种来源：

  1. 在线奖励（online-reward）
  2. 管理员 /qd givecard <玩家> [数量]
  3. 活动发放（可用其他插件调用命令）

补签后连续天数没恢复

确认补的是“连续链中间断开的那一天”。如果断了好几天，只补一天无法接上整条链。

排行榜

右侧计分板不显示

  • 确认 ranking.scoreboard-enable: true。
  • 检查是否被其他计分板插件顶掉（如某些称号、状态插件）。
  • /qd reload 会重建在线玩家计分板。

排行榜里没有某个玩家

从未签到过（连续 0 且累计 0）的玩家不会上榜。

配置与升级

升级后配置项丢失或报错

删除 plugins/QianDao/config.yml 让插件重新生成，再把自定义内容迁回新文件。升级前务必备份。

能热重载吗

可以，/qd reload 会重载配置、重新初始化经济联动、重建计分板。但不建议用插件管理器整体重载本插件，可能导致定时任务重复注册。

支持 1.13 以上吗

当前版本面向 1.12.2，材质名（如 SKULL_ITEM:5）与音效名都是 1.12.2 规范。需要其他版本请走 插件定制。

数据

数据存在哪

plugins/QianDao/data.yml，以玩家 UUID 为键，保存签到日期、补签日期、累计次数、已发里程碑、在线统计。

怎么备份 / 迁移

复制 config.yml 与 data.yml 到新服务器的同名目录即可，UUID 不变则数据通用。

会不会越来越大

不会。插件会自动清理 60 天前的日期记录。
