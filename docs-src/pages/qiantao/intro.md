# QianDao 签到插件

[[META:qiantao]]

> 一个 1.12.2 的签到插件。玩家点一下，奖励到手；管理员不用改代码，改 `config.yml` 就能调整整套奖励体系。

## 它解决什么问题

大部分签到插件只做到「每天给个东西」。QianDao 多做了一步：让玩家**舍不得断签**。

- 断签有补签卡兜底，不至于一天没上线就前功尽弃
- 连续 7 / 14 / 30 天有额外奖励，全服广播，面子也是奖励
- 右侧实时排行榜，不用管理员天天喊「今天谁还没签到」
- 金币直接进 ZPoints / PlayerPoints / Vault，不用再养一套经济系统

反过来也要说清楚它的边界：奖励全部通过**控制台指令**发放，所以能接任何物品、经济、点券插件；它不内置商店、不做每日任务，保持单一职责。这些需求交给别的插件，或者 [定制](定制服务)。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 每日签到 | 每天一次，默认凌晨 4:00 刷新（时区、刷新时间可配置） |
| 七日周期 | 第 1~7 天奖励逐天递增，第 7 天终极大奖，之后循环 |
| 连续奖励 | 连续 7 / 14 / 30 天额外奖励 + 全服广播，断签归零 |
| 补签卡 | 右键打开补签面板，可补最近 N 天漏签，补签后连续天数恢复 |
| 在线奖励 | 累计在线满设定时长自动发补签卡，每日有上限 |
| 签到排行 | 屏幕右侧实时计分板 + `/qd rank` 图形化排行榜 |
| 金币联动 | ZPoints / PlayerPoints / Vault 三选一 |
| 视听反馈 | 签到标题、音效、粒子、今日槽位附魔发光，全部可开关 |
| 数据安全 | `data.yml` 定时异步保存，自动清理 60 天前的旧记录 |

## 界面长什么样

**签到主面板（45 格）**

- 第 5 格：玩家头颅，显示连续天数、累计次数、补签卡数量
- 第 20~26 格：七日奖励展示，今天能领的那格附魔发光
- 第 32 格：补签卡与当前持有数量
- 底部：补签漏签日期 / 签到排行榜 / 关闭

**补签面板（27 格）**：列出最近 N 天可补签的日期，点击后二次确认，确认才扣卡。防止手滑，也防止玩家误点。

**排行榜面板（45 格）**：按连续天数排，同天数看累计次数。右侧计分板是同一套数据，每分钟刷新一次。

## 环境要求

- 服务端：Spigot / Paper **1.12.2**
- Java：**8** 及以上
- 可选前置：Vault + 经济插件、PlayerPoints、ZPoints

前置都是 softdepend：不装也能正常签到，只是对应金币奖励自动跳过，控制台会告诉你跳过了。

> 这是 1.12.2 专用构建，材质和音效用的是 1.12.2 的命名。1.13+ 请走定制，别硬塞。
