# 插件定制

> 接所有版本的 Minecraft 服务端插件定制。1.7.10 到最新版，Spigot / Paper / 混合端都做过。
> 不转包，不套模板，代码和文档一起交付。

## 先说清楚三件事

**一、需求越具体，报价越准。**
「做个抽奖」和「做个十连保底、概率公示、奖池分时段、抽完上全服广播的抽奖」是两个工作量。前者一句话能开工，后者得先对需求。

**二、能做和不能做都会直说。**
有些需求用现成插件改配置就能解决，没必要花钱写新的，我会直接告诉你。做不到的也说做不到，不接了自己也难受。

**三、交付的不只是 jar。**
一个只有 jar 的插件，换个人接手就是黑盒。所以配置、文档、指令权限表是默认交付项，不是加钱项。

## 常做的类型

| 类型 | 举例 |

| 签到 / 福利 | 每日签到、在线奖励、累计在线、兑换码 |

| 经济 / 商店 | 点券系统、GUI 商店、拍卖行、回收站 |
| 数据 / 统计 | 玩家数据面板、排行榜、战绩统计、数据看板 |
| 服管工具 | 封禁申诉、举报、工单、自动公告、活动配置化 |

## 交付清单

- 可运行的 jar，适配你指定的服务端版本
- 完整 `config.yml`：奖励、数值、文案、音效全部可改，不用来找我改代码
- 部署与配置文档，和这个站点里的文档同规格
- 上线后的问题修复；改动大的需求按阶段走

## 流程

1. **对需求**：玩法、数值、界面、依赖哪些插件，一次说清
2. **出方案**：功能清单、配置结构、工期和报价，确认后再动手
3. **开发联调**：按阶段给测试包，你在自己服上跑
4. **交付上线**：jar + 配置 + 文档，出问题随时找
