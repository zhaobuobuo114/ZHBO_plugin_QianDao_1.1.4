## 从哪儿开始

1. **先对版本**。服务端核心和 Java 版本对不上，后面全是白忙。每个插件第一页就写了硬性要求，别跳过。
2. **再装上去**。jar 丢进 `plugins/`，启动，看控制台。安装页给了正常日志和常见报错的样子，对照着看比猜快。
3. **最后调配置**。奖励、数值、文案都在 `config.yml`，改完重载，不用重启服。

## 这份文档的写法

- **只写验证过的**。配置项、指令、返回值，都是实际跑过才写进来。
- **版本对得上**。页面顶部的版本号就是当前文档对应的插件版本，不会拿旧文档糊弄新版本。
- **坑提前说**。容易踩的地方会单独标出来，比如「升级前先删 config.yml」，那是因为真的有人栽过。
